# Contributing

Use synthetic fixtures. Never commit transcripts, a ledger database, a user's diagnostic report, real names, home paths, credentials or screenshots containing private chats.

Run `python3 -m unittest discover -s tests -v` and `node --check token_trail/web/app.js`. Accounting changes need a fixture showing the concrete provider record shape and why the previous arithmetic failed. Keep exact counters separate from estimates. Do not add remote AI labeling, silent model downgrades, or analytics by default.

UI changes should preserve keyboard navigation, the neutral/green palette, one corner-radius system, mobile readability, and clear units. Test empty states, stale collectors, rolling windows, filtering, and conversation drill-downs.

No public repository has been created by the local installer; use your chosen source host when you are ready to publish.
